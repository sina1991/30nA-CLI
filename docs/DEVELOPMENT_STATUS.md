# وضعیت PoC

سه Agent عملیاتی Calculator، System و Host با Discovery، راهنمای مستقل، نصب Bash و SQLite پیاده‌سازی شدند. ۹ تست روی Linux محلی اجرا و قبول شدند. نصب مجدد داده Host را حفظ کرد. اتصال به سرور واقعی در معیار پذیرش نیست و با Mock بررسی شد.

محدوده نسخه شامل کاربر و پورت SSH از تنظیمات استاندارد OpenSSH، اطلاعات جاری Linux و محاسبات Decimal است. برای ادامه، ابتدا branch و SHA واقعی را بررسی کنید، تست‌ها را اجرا کنید و برای هر تغییر قرارداد CLI راهنمای کاربر و تست آن را به‌روز کنید. مخزن هنگام شروع هیچ Commit یا branch منتشرشده‌ای نداشت. وضعیت انتشار و PR را در GitHub بررسی کنید.
