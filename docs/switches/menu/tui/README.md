# `-menu -tui`

مدیر فایل تعاملی با curses.

```bash
clear
30na -menu -tui
```

خروجی یا اثر مورد انتظار: رابط تمام‌صفحه در ترمینال.

[راهنمای کامل Agent](../README.md)

برای مرکز کنترل Agentها، بدون -dir اجرا کنید:

```bash
clear
30na -menu -tui
```
