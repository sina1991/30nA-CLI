# 30na -menu

برای ورود به ریشه `30na -menu -dir / -tui` و برای خانهٔ root مسیر `/root` را بدهید. مسیر نسبی از محل اجرای دستور محاسبه می‌شود. ROOT و root در صورت نبودن مسیر محلی هم‌نام به / اشاره می‌کنند. فلش بالا و پایین انتخاب، راست ورود به پوشه و چپ رفتن به والد است. Enter فایل متنی را با nano در همان ترمینال باز می‌کند. Ctrl+O و Enter ذخیره، Ctrl+X خروج است. پس از خروج، انتخاب و فیلتر حفظ می‌شوند. از عرض ۸۰ ستون، پنل دوم ابتدای فایل UTF-8 انتخابی را تا ۱۶ KiB نمایش می‌دهد. p بین پیش‌نمایش و مقصد جابه‌جا می‌شود. Tab پنل مقصد را فعال می‌کند. c کپی، m انتقال، r تغییر نام، n فایل جدید، d پوشه جدید، x حذف با تأیید، / فیلتر، g رفتن به مسیر و ? راهنماست.

- [-dir](dir/README.md) — انتخاب مسیر شروع
- [-text](text/README.md) — منوی شماره‌ای
- [-tui](tui/README.md) — مدیر فایل تعاملی با curses
- [-gui](gui/README.md) — رابط Tk یا TUI در SSH تعاملی بدون DISPLAY
- [-help](help/README.md) — راهنمای سوییچ‌ها و مثال‌های Agent

در مدیر فایل TUI کلید `.` نمایش فایل‌ها و پوشه‌های نقطه‌دار را برای هر دو پنل روشن یا خاموش می‌کند. در ابتدای هر اجرا نمایش روشن است.
