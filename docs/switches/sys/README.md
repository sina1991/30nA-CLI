# 30na -sys

فیلدها را جدا یا کنار هم بخوانید. مثال: `30na -sys -hostname -kernel`. ترتیب خروجی مطابق جدول زیر است.

- [-hostname](hostname/README.md) — نام میزبان
- [-os](os/README.md) — نام توزیع Linux
- [-kernel](kernel/README.md) — نسخهٔ Kernel
- [-uptime](uptime/README.md) — زمان روشن بودن بر حسب ثانیه
- [-cpu](cpu/README.md) — مدل یا معماری CPU
- [-ram](ram/README.md) — حافظهٔ کل
- [-disk](disk/README.md) — فضای کل، مصرفی و آزاد فایل‌سیستم /
- [-help](help/README.md) — راهنمای سوییچ‌ها و مثال‌های Agent
