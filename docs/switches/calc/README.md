# 30na -calc

دو عدد را در آرگومان‌ها یا با فاصله روی stdin بدهید. مثال: `echo '1.2 3' | 30na -calc -mul`. تقسیم بر صفر و ورودی نامعتبر با کد ۲ گزارش می‌شوند.

- [-add](add/README.md) — جمع دو عدد
- [-sub](sub/README.md) — تفریق عدد دوم از اول
- [-mul](mul/README.md) — ضرب دو عدد
- [-div](div/README.md) — تقسیم عدد اول بر دوم
- [-help](help/README.md) — راهنمای سوییچ‌ها و مثال‌های Agent
